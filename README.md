# ExpenseTracker
It is an REST API made in Spring Boot with Spring Security for authentication using JWT token , for managing Income / Expense.

It is deployed on cloud and available at
> [expense-tracker-7d14.onrender.com](https://expense-tracker-7d14.onrender.com)

## Common Endpoints
Register - /register
Login    - /auth/login
Logout   - /auth/logout

It is expected first to login and attach the Bearer token in the response for every request sent.
